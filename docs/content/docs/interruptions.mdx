---
title: Interruptions
description: The caller says a fixed line while the agent speaks.
---

A scenario can make Yaksh's caller interrupt the agent: the caller says a fixed line while the agent still speaks. Use interruptions to test whether the agent stops when a caller talks over it, and what it says next. Interruptions play on phone calls only, while the persona is on the line. A text run, a call that the persona's voicemail answers, and the time before a call screener hands the call over have none.

A scenario has up to 3 interruptions:

```yaml
interruptions:
  - agent_says: first visit
    say: "Sorry, is there a fee for that?"
  - after_s: 3
    say: "Hold on, can you say that again?"
```

| Field | Meaning |
| --- | --- |
| `say` | The caller's words, 1 to 200 characters. A `{{Fact name}}` placeholder takes the data set's value. |
| `agent_says` | A phrase. Each time the agent says it, a wait of `after_s` starts. Without a phrase, a wait starts when the agent starts to speak in each of its answers. |
| `after_s` | The wait in seconds, from 0 to 30. The default is 0 with a phrase, and 2 without one. |
| `from_answer` | The first answer of the agent that can start a wait. Answer 1 is the agent's first speech, often its greeting. The agent's next answer starts after the caller replies or presses keys. The default is 1 with a phrase, and 2 without one, which skips the greeting. |

## When a line plays

- The line plays when a wait ends and the agent still speaks in the same turn. The agent cannot cut the line.
- When the wait of a line with no phrase ends while the agent pauses, the line plays when the agent speaks again in the same turn. A line with a phrase does not wait for that.
- A wait is used up, and the line waits for its next start, when the agent's turn ends first, when the caller is speaking, when the caller pressed keys in that turn, or when another line plays or its window is open. The window of a line is 2 s from its first sound.
- Each line plays at most once, and one line plays at a time.
- A phrase matches whole words only: "fee" does not match "coffee", although a phrase rule finds it there. As in a phrase rule, numbers, dates and times match in words or in digits. But digits do not join across punctuation: "five five five, oh one four two" does not match "5550142".
- A phrase needs the agent's words while it still speaks. Deepgram, AssemblyAI, Soniox and Gladia give them. Sarvam gives them only after the agent stops, so a run start refuses a scenario with a phrase when Settings use Sarvam. A line with no phrase works with every provider.
- Yaksh makes the speech of each line with the persona's voice when the call starts. A line whose speech failed does not play.

## What the caller does next

When the agent turn that a line interrupted ends, the caller's model learns that it said the line. Then:

- If the agent stopped for the line within 2 s of its first sound and said nothing more in that turn, the caller waits for the agent's answer. If the agent then says nothing for 3 s, the caller goes on with the call.
- If the agent stopped and then answered in the same turn, the caller replies to the answer.
- In all other cases, for example when the agent talked over the line, the caller replies to the turn as usual.

A line that asks the agent to wait, such as "Sorry, one moment.", works: when the agent says that it will wait, the caller says that it is back and goes on. Backchannel lines, such as "Mm-hmm.", are not supported yet. The caller treats them as lines that the agent stops for.

## Results

- The transcript shows each line as a caller turn with the label "Yaksh's fixed line". The line comes after the agent turn that it interrupted, because that turn is kept whole.
- The judges see where each line came. After the line's turn, one more line tells them how far into which agent turn the caller spoke, and after which words of the agent. The judges judge the call as they judge any other call.
- Nothing checks yet how fast the agent stopped. To check what the agent did after a line, write a criterion, such as "The agent tells the caller the fee for a first visit." Refer to [Writing criteria](/docs/writing-criteria).
- The recording in the **Audio** card of the call has both sides, the agent on the left and the caller on the right, so you can hear how the agent stopped.
- The lines count in the caller's speech, but not in the agent's response time, because the caller said them over the agent.
- Each start of an interruption is saved with the conversation, with its outcome: played, or why it did not play, such as "turn_ended". The API returns them in the conversation's `wire_events`, with the kind `interruption`.
