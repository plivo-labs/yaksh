Truman does tests of AI voice agents. A simulated caller speaks with your agent on a phone call and follows a scenario. Truman records each call. Truman is open source, and you operate it on your servers. [Plivo](https://plivo.com) makes Truman.

## Terms

| Term | Description |
| --- | --- |
| Agent | The voice agent that you do a test on. Truman calls the phone number of an inbound agent. An outbound agent calls Truman. |
| Persona | How the caller speaks: a prompt, a language, a voice and background noise. |
| Scenario | A goal, the facts that the caller knows, the facts that the caller does not have, and the criteria. The criteria are the tasks of the agent on the call. The caller gets the goal and the facts, but not the criteria. Each scenario has a persona. |
| Conversation | One call between the caller and an agent. Truman keeps the transcript, the recording and the wire events of the call. |
| Run | The conversations of one or more scenarios of one agent. A run can start each scenario more than one time. |

## Parts of Truman

| Part | Description |
| --- | --- |
| API | The console and the HTTP API, on port 8000. |
| Worker | The process that makes and gets the test calls. Plivo sends the call audio to port 8770 of the worker. |
| Database | Postgres keeps the agents, the scenarios, the personas and the conversations. |
| Data folder | The worker writes the recording of each call to this folder. The API reads the recordings from the same folder. Docker Compose keeps the folder in the `truman_data` volume. |
| File storage | S3-compatible storage keeps the documents that you upload. |

## How Truman does a test

1. Truman makes the instructions for the caller from the scenario and the persona.
2. The worker calls the agent. For an outbound agent, the worker sends a trigger, and the agent calls Truman.
3. The caller speaks with the agent. When the caller speaks first, it says the first words of the scenario, with no model call. The caller also says them when an agent that should speak first says nothing for 15 seconds. A scenario without first words uses the default of the persona's language, "Hello" for English and Hinglish. The call stops when the caller completes its goal or when the agent disconnects. The call also stops if the agent does not speak, or if you stop the call. Limits on the duration and on the number of turns also stop the call.
4. Truman keeps the conversation and measures the [response time](/docs/response-time) of the agent.

Truman does not give a pass or fail result at this time. To find if the agent did its tasks correctly, compare the transcript with the criteria of the scenario.

## Services

Truman uses these services. You must have an account with Plivo, Deepgram and ElevenLabs. You must also have an account with OpenAI, or with a different service that has the OpenAI Responses endpoint.

| Service | Description |
| --- | --- |
| Plivo | The phone calls. |
| Deepgram | Speech to text. It hears the agent. |
| OpenAI | The persona model writes the text that the caller speaks. A model also writes scenarios. |
| ElevenLabs | Text to speech. It makes the voice of the caller. The API also uses it to find voices and to play previews. |

The caller is a [Pipecat](https://github.com/pipecat-ai/pipecat) pipeline in the worker. Pipecat is open source, and it does not use an account.
